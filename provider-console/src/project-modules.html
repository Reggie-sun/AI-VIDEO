项目模块全景

AI-VIDEO 把创作意图转成可执行的制作计划，再连接模型生成、剪辑、声音、渲染与验收。Agent 决定创作方向，模型生成原始媒体，程序负责约束、加工和记录证据。

SOURCE-BASED EXPLANATION

这是基于当前代码职责整理的架构说明，日期为 2026-10-20。它不读取或显示某个项目、Shot 或任务的实时状态。

26个功能模块
3条职责泳道
5种架构视图
4层独立能力证据
01 / INTENT

Agent 创作

理解剧本与目标，设计人物、动作、摄影、表演和镜头方案；Skills 提供创作方法与参考。

02 / MEDIA

模型生成

所选 Provider/model 根据 Prompt 与绑定的素材产出原始图像或视频；参考与文字提供引导。

03 / EXECUTION

程序执行

检查输入与授权，管理状态，完成剪辑、声音和渲染，并把结果与验收证据关联起来。

生成是有边界的反馈闭环

检查结果回到失败分析与制作策略；可复用或可编辑的素材可以绕过重新生成。虚线表示需要 Agent 明确发起的工作流动作。

回环不表示自动重试：新生成仍需当前授权、有限额度与一次性许可。UNKNOWN 先停止并查明结果；缺证据先补证。开发修补预览保留原片失败历史。
