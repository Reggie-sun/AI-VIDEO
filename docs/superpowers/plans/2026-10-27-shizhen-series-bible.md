# Lost Frames Series Bible Plan

## Goal And Authority

落实本轮完整世界观 V1 与长期连载创作要求，沿既有 `docs/superpowers/artifacts/drama/shizhen-episode-01/` 增补系列创作资料。使用 `superpowers:writing-plans` 固定本轮边界，随后直接完成创作。Parent 是唯一 writer；只读历史调查与最终交叉审读不写文件。

本轮授权完整创作与必要重构，但不授权把新提案升级成制作 Canon。原 `screenplay.md`、`production-design.md`、coverage、认可声画、ProductionProject/Registry/Manifest 全部保留。已有 dirty paths 归其他工作，本轮不编辑或 stage。

## Files And Owners

同一项目目录新增 `series-index.md` 作为阅读入口；`world-bible.md` 独占底层规则；`ability-bible.md` 独占能力操作与代价；`character-bible.md` 独占新增人物关系与弧线；`faction-bible.md` 独占组织；`anomaly-bible.md` 独占异常分类与个案；`timeline.md` 独占作者历史排序；`series-outline.md` 独占第一季整体框架；`season-01-outline.md` 独占第一季分集；`canon-review.md` 保存来源、保护边界和矛盾检查；`creative-decisions.md` 保存 V1 对照、未决项与综合审读。其他文档引用规则编号，不复制第二套解释。

## Milestones

1. 重开原剧本、设定、冷开场与关键历史；区分已确定故事、exact 媒体批准、历史试片及未验证提案。旧照片、未来元数据、2022/2026 年龄与十一秒算术逐项核对。
2. 完成十类实质稿与索引；覆盖 V1 六能力、五立场、补帧者三认知类型、兄妹秘密、十六逻辑问题、第一季高潮与完整分集。重大调整用原方案→推荐→理由→收益→Canon 影响追踪。
3. 对稳定候选做规则、人物知识、日期、伏笔、公平线索与非主角行动交叉审读；相称文档/Harness 检查，修复确认问题。编剧可持续性与可拍性属于文本判断，媒体与观众验收为 `NOT_EVALUATED`。
4. 用现有记录 skill 留一个稳定 checkpoint，学习评估无跨实验新证据则 `no_candidate`。只 stage 本轮明确文件，验证后 commit/push `main` 并核验远端 SHA；失败如实报告。

## Acceptance And Verification

- 四种知识状态显式：`CONFIRMED CANON`、`PROPOSED CANON`、`AUTHOR SECRET`、`OPEN QUESTION`；作者秘密是推荐模型中的秘密，不是另一条确认渠道。
- 16 个逻辑问题有互相兼容答案；重要角色有独立动机/秘密/行动/弱点/弧线/实质关系；每集有因果推进、代价与信息边界。
- 本轮不执行图片、视频、音乐生成，不覆盖媒体，不修改平台或 Production state。
- 运行 docs contract、Markdown 本地链接与目标覆盖核对；按 policy 对 exact staged snapshot 运行适用 Harness，保存 receipt 并验证。未运行 full 时不声称完整工程回归。

## Self Review

用户要求的是创作成品，本计划不替代成品。沿原项目增补，无第二运行链或时间线；叙事历史表不是 `ResolvedTimeline`。Canon 批准与 Git 发布相互独立。

## Incorporated Survival Direction

工作中用户明确补充现实校正、补帧猎杀、异常区域、能力对抗、势力围捕，要求最前两种尽早出现与主角活过下一03:17。新增 owned file `episode-01-survival-revision.md`，给出不覆盖原片的可演出店外袭击与工作室衔接；五类威胁、陆衡主要对手、完整第一季均按此优化。六能力、五立场与原结尾仍保留；新场景仍属待确认创作提案，不自动submit或修改coverage。

## First-Season Scope Override

用户最新明确“就写第一季就够了”。本轮撤出未确认的未来季剧情，保留第一季12集、六能力、五立场、八类异常与作者层必要规则；人物弧线、揭露表、决策表和索引均同步到本季边界。该变更是用户缩小范围，不是Canon确认，也不授权新媒体。
