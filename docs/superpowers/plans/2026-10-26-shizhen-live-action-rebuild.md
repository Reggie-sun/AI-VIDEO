# Lost Frames Live-Action Opening Rebuild Plan

## Goal And Scope

保留最新宏观→社会→空间→微观异常的开场目标，将整集视觉从CG改为用户参考图级别的真人摄影观感。旧剧本、原片、动作、对白、音乐与历史验收不覆盖；真人画面独立版本。当前不新增付费生成。

## Ownership And Compatibility

本窗口仅写 `outputs/shizhen-episode01/live-action-rebuild-20261026/`、本计划及独立checkpoint记录；不修改并行S03或旧CG project/manifest。Native Codex负责实施；`open-video`拥有导演决策，新的motion/type技能只补充方法，HyperFrames/ResolvedTimeline与Music Director/Suno原有owner保持。

## Milestones

1. 已完成整集审读、旧片密集抽帧复核、用户参考职责绑定、三项技能定版安装及新视觉范围登记。以原31段叙事与表演为保护内容，不机械拼接CG原文与“真人”两字。
2. 已准备城市收束与两位事件的中文输入、S01迁移说明和v4导演覆盖；实际执行仍缺真人身份/场景素材、exact profile/asset binding及新付费授权。`execute_ready=false`，不submit，不复用旧permit或重置历史计数。
3. 本地P4输出独立片名与翌夜字体测试，实际核验字形、层级、可播放性与源文件未变。测试不替代真人剧情视频，不以全目标PASS交付。
4. 后续真人素材具备后才制作整段：逐镜exact MCP、正常速度表演/声音与接缝复核，经唯一Composition/ResolvedTimeline/HyperFrames合成，按用户七项指标与旧版比较；用户认可后再全量工程验证及owned-path commit/push。

## Acceptance And Current Limit

最终应体现城市生活向个人缺席收束，演员与空间统一实拍观感，保住“两位→一位”的平静反差、原音乐、时间逻辑、S01动作/对白及结尾信息边界。独立字体输出只证明后期排版的局部可实施性；真人画面、成片混音与整体吸引力当前均未验收。缺失素材与当前禁止新增付费生成是实际停点，不能以静图推拉或旧CG混剪关闭任务。
