# Lost Frames — Series Development Index

## Status And Reading Contract

版本：2026-10-27，整合完整世界观 V1 与后续“活过今晚”创作修订，按用户最新指令仅写第一季。核心命题：**每一个消失的人，都在替这座城市偿还一段不存在的时间。** 叙事发动机：**当整个世界决定你不应该存在时，你要怎样活过今晚？**

这是当前《失帧》项目内的系列创作开发稿，文档正式落盘不等于新设定获准用于制作。没有改写原剧本、生成提示词、认可媒体或 Production state。后续创作先读本页和 [Canon Review](canon-review.md)，避免把旧试片、作者推断及本轮推荐混为一谈。

| Label | Meaning |
| --- | --- |
| CONFIRMED CANON | 已有用户故事要求、现行剧本中的确立事实，或有明确出处的创作决定；须注明是故事事实还是 exact 媒体批准，二者不互推 |
| PROPOSED CANON | 本轮推荐的新事实、结构、关系或修订；等待用户创作确认，不得自动成为新 Shot 的制作依据 |
| AUTHOR SECRET | 推荐模型中作者必须统一掌握、观众暂不知道的解释；继承 PROPOSED CANON 状态，不是隐蔽的批准渠道 |
| OPEN QUESTION | 作者主动留下的可选项，须注明推荐与受影响边界；不得暗中改变已给出的规则答案 |

除各文档明确标为 CONFIRMED CANON 的来源段落外，本套新增内容统一为 PROPOSED CANON。AUTHOR SECRET 只改变揭露对象，不改变批准等级。方案获确认时应精确注明采纳的文档版本与决策编号，不能凭“整体不错”推定所有备选获准。

既有 [screenplay.md](screenplay.md)、[production-design.md](production-design.md)、[director-coverage.json](director-coverage.json) 与 [cold-open-preparation](cold-open-preparation/README.md) 保持原 owner；制作记录会修正这些文件中未同步的历史状态，详见 Canon Review。

现有旧稿采用原创CG；2026-10-26用户后来明确改为“全部变成真人感觉”。本轮要求考察高质量3D影视表现，不自动取消这个历史视觉决定：系列场景提供可用于3D制作的空间、灯光与动作设计；**当前输出风格不在本轮重新选择**。本轮没有查看或验收新的连续声画，也没有付费图片、视频、音乐生成。媒体与观众可读性均保留 NOT_EVALUATED。

## Recommended Creative Position

先让观众在一间便利店失去常识，再让主角在一条巷子失去安全。能力解决的是“从哪里多争取一个选择”，而非“终于可以打赢世界”。第一季结束必须让林序活过他拒绝牺牲别人换来的那一夜，同时失去一个不能用下次胜利补回的人际位置。

五个阵营都必须有救人的事实和伤人的选择。自觉体陆衡是第一季具体的主要灵异对手；余像群不因他的犯罪失去存在权。林晚在哥哥之外有必须保护的人，最终救援不能默认所有失踪者愿意回到原来的生活。
