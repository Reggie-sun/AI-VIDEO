## Visual Language

电影级原创 CG 国漫写实：正常成人比例，略作设计的颧骨和眼睑、清楚的面部形体、细束发片与可辨的 CG 皮肤高光；布料、金属、雨水接近物理真实。主角、店员、店长、骑手、妹妹及录像里的人物保持同一渲染语言。禁止真人照片脸、蜡像、Q版、游戏待机循环。环境真实不等于人物变成实拍。

便利店是偏青的荧光顶灯加微波炉暖光，人物眼窝必须可读；异常前后同一曝光，不靠突然全黑遮掉消失。工作间为窗外青灰雨光、桌面2700K暖灯和不溢出的屏幕光。妹妹走廊只有远端残余冷光与镜头附近弱反光，能看清她的眼神、门框和人影；不能全黑后靠对白解释。

## Store Space And Axis

长方形小店。南侧玻璃入口；北侧收银柜台横向排列，柜台西端通道连后仓门，东侧微波炉；东墙冰柜，中央两排低货架。电子钟在柜台后上方。林序在柜台南侧偏西，店员在北侧，骑手在林序东后方靠微波炉。唐姐事发前在后仓，事后从西通道进入。

主要摄影机在顾客这一侧，林序视线朝北、店员视线朝南；切侧近景也保持柜台轴线。监控是已经建立的东南高位机，第二机位在西南，不用未建立的超现实反打。消失使用同构图的表演源与空柜台源按同一编辑切口表现，角色“不见了”必须在正常速度下可读，不能只让摄像机摇开再回来。

物件连续：饭团最初在微波炉加热，店员递到柜台；咖啡是一瓶黑金瓶装咖啡，未开封；林序一台黑壳手机，右手亮付款码，后放下；饭团下的白纸、后来付款的小票明确不同。最后拿走的食品与付费发生在唐姐出现后，不能让异常前已经打印的收据成为另一套时间。

## Studio And Video Space

工作间北窗、东侧工作桌，双屏并排；暖台灯在画面左，照片原放台灯底座，小票由林序进屋带来。林序坐桌南侧。现实机位沿桌南侧活动。录像中的走廊不建立为工作间；门框和固定的一盏坏灯负责空间识别，不添加第四个陌生地点。

监控画面、文件属性、日期、帧号和修复 UI 由后期图形按准确文本合成到已规划的显示器平面；视频模型负责人物和空间，不负责拼写关键证据。素材阶段屏幕可以有低亮稳定的中性底，不能拿空屏当完成了叙事。所有 UI 信息最终经同一 CompositionSpec / ResolvedTimeline / HyperFrames 出片；未核验投影能力前不承诺完成跟踪合成。

## Reference Duties

最小参考集为林序、小程、唐姐与骑手、林晚、便利店空间、工作间、录像走廊；多人合图不能交叉继承脸和衣服。正式生成前按实际可用图片拆出独立身份与空间参考。身份图只迁移相貌、服装、CG语言，不锁住静止姿态；空间图只迁移几何、陈设和灯光，不引入多余人物。参考尚未产生的占位名不能进入 native 请求。

连续表演镜须先核验前镜真实终态和声音尾部，再决定参考片段或真实末帧；故事上的切镜可以改变景别，却不能让未放下的手机突然消失、已收回的手又伸出去。不同场景有明确时间省略；不能把这一省略滥用于同一动作。

## Sound Design

便利店开场用冰柜、纸张、扫码、微波炉和后仓纸箱建立生活。03:17的异常是扫码音和环境床的一次非自然缺失，恢复后以微波炉正常结束音反衬；不反复套用同一低频冲击。店长递水时可以只留瓶底碰台和呼吸。雨夜过门用真实雨声连接。

工作间先有电脑风扇和隔壁管道声；发现多源缺口后降低配乐依赖，保留瓶盖尚未拧开的细小动作。妹妹录像声音窄而近，哥哥回应是房间声，两者空间必须有区别。画外摩擦声只在妹妹听见时改变她的行为，不能让现实林序像同处走廊那样转身定位。结尾真实雨声继续，不能把整集环境静音变成万能恐怖手段。

原生对白和表演音优先 GENERATED / KEEP；后期只补必要环境、关键时间异常与准确图形，不覆盖对白。音义、说话人、反应和口型须对同一 MP4 实证；ASR或音轨存在不代表声音验收。字幕从通过的实际声画转写对齐，不能预先逐句分配固定时间。
