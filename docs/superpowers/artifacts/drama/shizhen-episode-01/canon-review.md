3. **来源与敌意分开：** 校正无人格，接人者可被陆衡利用；没有把所有怪物／人类组织串成世界同一个意志。
4. **自救有先验线索：** 门、路径、落点和声音先呈现，后推断；不存在最后一句新规则救场。
