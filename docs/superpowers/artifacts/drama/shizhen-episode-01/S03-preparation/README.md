# S03 — A Checkout With No One Behind It

## Scope And Audience Effect

接用户刚认可并允许续拍的S01–S02剪辑修正版，开始店员消失。观众先确信小程仍在正常工作，再看清同一空间的人已经不在；林序比观众慢半拍，仍把眼前状况当成普通的结账中断。恐惧来自缺席，不是闪光、怪物、烟化或大喊。

## Actual Handoff

小程在柜台左侧，左手扶黑金咖啡瓶，瓶底由台面支撑，右手持扫码枪靠近瓶身。林序在右侧，右手已经取出并举亮手机；不重演取枪、取手机或微笑。三角饭团在原白纸上，纸与饭团都保持原位置，暖货架和冷雨窗保持。手机只保留已观察到的亮屏，不将旧画面虚称已显示清晰付款码。

三张同源参考分别负责林序身份、小程身份、实际接点状态。两张身份图不迁移其旧时刻的动作和道具；状态图不把低机位裁脸继承为新镜的摄影限制。骑手保持画外，不为凑人数让他出场或跟随异常表演。

## Ordered Coverage

全段约10秒，一次生成预算，两个摄影机位、三个戏剧单元；不按每句话或动作分配时间戳。

1. **S03-A / established presence**：同柜台轴线切到双人中景，完整看见小程和林序的脸、瓶枪与右手手机。小程正常看条码，食指开始压扳机；林序视线落在瓶身与扫码枪工作点，没有正盯着店员的脸，继续等付款。摄影在此停住，让存在成为可核对的事实。
2. **S03-B / absence**：一次没有过程的同构图硬切，灯光、柜台、饭团白纸、原瓶与林序举手机的身体关系保持；小程与衣服整体已不在，林序头向与低落工作点的视线先延续。枪落在原手下方的台面，不悬浮、不跟着人消失，咖啡仍直立。缺掉的十一秒发生在这个省略断口，不让观众等待十一秒，不用黑帧、眨灯、慢溶或残影代替。
3. **S03-C / delayed recognition**：切同轴林序中近景。从同一低落工作点的视线与右手举手机姿态接起，先等一个回应，等不到才抬眼找人、看向空位，眉心收紧，视线探向柜台下，身体轻微前倾；仍未确认发生了什么。手机保持同一右手，暂不收回口袋。片尾停在他准备开口询问之前，下一镜才问“还没扫上？”；本镜没有新对白。

前两个单元的同构图保留是为了让观众比较存在与缺席；最后切近景是为了读到迟疑，不能整段锁成一个低机位长镜头。摄影视点不越柜台轴线，镜头不以无意义推近替代表演。

## Sound And Time Evidence

冰柜、电器与远处车流先连续。扫码提示音只起一个不完整的头，随失帧断口缺掉一截；短暂的声场缺口后，普通电器底噪回来。林序的衣料、呼吸随动作保持自然，无恐怖配乐、重低音惊吓或成功付款提示。

不让生成模型承担精确电子钟数字，也不把没有钟面的原片宣称为已证明十一秒。城市03:17与十一秒的精确证据仍由整集后续屏幕/监控证据段落承担；本镜只完成真实的人消失这一事实，不取消全剧的时间规则。

## Review Criteria

必须能比较正常在场与同框缺席；不能拍成店员蹲下、走出画面或被遮挡。消失后没有其他人顶替、镜中残留店员或衣服落地。原瓶、纸、饭团、手机的状态延续；枪的无人支撑状态明确落台。林序先等再疑惑，不提前恐惧、木脸停滞或突然惊叫。风格保持已认可D版成年原创3D CG。原片先审，认可后按既有中英双语/句尾无符号规则处理；无对白片段不凭空添加字幕。

精确同构图缺席、物件状态及声场断口均为待真实成片验证的高风险项，文字或参考通过不等于已实现。新片须显式MCP逐项检查，再与已认可连续版一起检查实际接点；任何FAIL/NE不推进S04。
