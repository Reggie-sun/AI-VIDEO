## Shared Contract

状态：PROPOSED CANON，含本轮V2整合。来源、现实边界与代价以 [W01–W15](world-bible.md) 为唯一解释。六能力采用已落实的新名称，V2来稿中的拼帧／闻缺／定帧／借帧／索帧／留帧依次对应拾遗／余响／守更／借步／验契／留影；人物身份不变。日常对白先说“我能听见刚才没发生的那句话”，不让新角色先报技能名、等级和数值。

留底人是删除／改写没有完全收束时，人的某项真实联系跨在两侧的幸存者。接触异常不必觉醒；设计事故、濒死训练、强迫记住名字都不能稳定制造能力者。形成差异取决于残留载体与当事人当时在做的行动：看、听、固定、穿行、识别关系、留住片段。人格影响使用选择，不是性格决定超能力的玄学考试。

一人通常只有一种稳定操作。学习可以扩大对原操作的理解，不会通过杀敌解锁另一人的能力。器材提高取证和定位效率，不能凭设备赋能。林序早期技术修复与被动留忆不是已完成一次主动拾遗；原第一集不倒填觉醒特效。

## Development And Accumulation

发展仍有四种可交错的熟练状态：**受动**（经历现象，无法重现）、**辨识**（知道何时不该相信感知）、**可控小操作**（限定来源与目标）、**复杂协作**（别人补上本能力无法完成的部分）。V2另用P级评估已证明的干预深度；两者不互换。P1可以是极熟练的专家，P3也可能只能在一个极苛刻条件下成功。失去来源、感官或关系后可衰退；有经验的人也会误判。

代价分为即时消耗、持续损伤、不可逆断联。即时眩晕、缺氧和疼痛可恢复；听觉与面孔处理损害要长期适应；某段已被删除的共同经历不能睡一觉回来。不同能力的代价不能变成通用点数。

每次重要使用都要写清：现有源 → 有限操作 → 当下结果 → 谁失去了什么 → 此后生活怎样改变。先定代价的受影响关系，再写高潮，不能事后随便挑一个不再出场的熟人支付。普通工作和新相处可以重建今后的关系，不能回补旧人生。

## Intervention Depth — P0 To P5

**PROPOSED CANON / V2。** 以下保留用户给出的阶位暂名，作为堤务处内部评估用语；其他阵营不必承认其命名权。它们衡量跨现实干预的深度，不是官职、招式数量或战力积分。高一级不自动包含低一级的全部操作，也不承诺每种能力都能达到P5。

| Code / temporary name | What must actually be demonstrated | Boundary and survival implication |
| --- | --- | --- |
| P0 留痕 | 被动保留与当前历史不相容的亲历／感觉，尚不能主动重现异常操作 | 留忆不是攻击、防御或免删；普通证人相信异常也不自动成为P0 |
| P1 窥帧 | 有条件地主动寻找、感知或读取真实残迹 | 信息可以救命，但看见不等于能干预；普通修复、推理和观察本身不算能力证明 |
| P2 触帧 | 令自身或一个明确对象短暂接入一个已有源状态 | 可以是门的一次动作、自己的有限路径；随后引起普通物理后果不自动升P3，不自带护甲 |
| P3 牵因 | 在真实接缝中，直接接通／维持数个原已有关联的节点，使他人可参与一段本来缺失的行动因果 | 有人受影响不等于控制其意志；门开后别人自己走过不自动算牵因，必须证明能力直接维系了跨节点关系 |
| P4 立域 | 在已验证的边界内持续维持同一种有源干预，处理多次相继出现的冲突与状态变化 | 规则内容由原能力决定，不得自创“谁说谎谁死”；面积不是判据，不能把一次预设保护简单放大成整栋楼 |
| P5 裁史 | 对一个来源充分、外部依赖已核验的有限冲突，令一段真实候选历史被共同当下采纳，而非只临时接入动作 | 仍有互斥损失与外部风险；不能任意回滚年份、令2022事故从未发生、复活源已耗散者或证明这条历史更正当 |

P4的“一栋建筑”只是满足完整源、实体边界、持续承载与撤离条件后可能出现的规模，不是到级送的面积。周竞本季的预设保护屋针对同一窗口、同组来源的一次覆盖，推荐按P3条件性操作处理；它尚未证明能持续接住多个独立新冲突，不能据此宣布P4已成。

P5暂列理论深度，第一季没有已核验施行者。设备、多人共同救援、零帧事故和全城封闭不能直接换算成某个人P5。所谓恢复“被删除者”，只在仍有身体／来源、可用出口与相容接应时才可研究；真正源耗散不被改成可随时撤销的死亡。

评估记“已证操作、具体条件、来源可信度、当前损伤、待证上限”，不只写一个最高级。一次外部支撑下的越阶效应，须标“本次条件性”；未复现不授予常态等级。失控影响大也不证明生前会稳定施展同规模能力。

曾证深度与当前可用程度分别保留：某人曾做到P3，源已失活或身体失控后，本次可能连P1都不能可靠执行。不能删除旧成功，也不能拿档案最高级要求伤者照常出勤。

## Growth, Verification And Refusal

成长经过**接触更深异常、理解原能力的新用法、以真实存在关系承担更大负荷**，三者缺一都不能靠意志或杀敌补齐。接触更危险事件只是遇到新条件，可能只受伤、失去能力或死亡。锚的适配与代价转移均引用W14，不另定“锚点够多就升级”。

训练先用来源清楚的小残迹，明确本次只想改变／读取哪一项，留一名未参与操作的观察者；把原件、感知证词和当下实际结果分开。重复成功后才扩大**一个**条件，不同时增加范围、目标和持续时长。出现失认、现时感知失效或来源不兼容即停止；这能降低新损伤，不能撤销已付代价。

突破前必须有原操作的连续依据；突破中展示新接通的具体节点；突破后保留未获能力、失去的关系与下一次做不到的事实。人物拒绝继续提升可以是清醒选择，不能被写成怯懦；组织也不能把评估低当成可以牺牲他人的理由。

## A01 — Lin Xu / 拾遗

**戏剧职责：** 从“我记得”跨到“我们能验证并利用一个已丢失的动作”；既能取证，也能在对抗中找出生路。不是掌握最终真相的万能侦探。

- **起始条件：** 真实残迹足以约束缺口，例如相邻原始帧、被改写前后仍连着的物件动作、同一事件的声音与空间证据。只有名字、一张陌生脸或想象不能开工。
- **早期：** 保留亲历；辨认不同来源不一致。只能用职业技能恢复本已可见的像素，不能借“能力”把猜测洗成影像证据。
- **中期：** 将一个仍残留的短动作接回局部感知或现有记录的工作副本，标清源与恢复边界。若两种历史都支持不同解释，就只恢复共同能证明的部分。拼出“门曾向内打开”，不等于知道谁是凶手。
- **后期：** 在实际接缝中暂接一段已有动作，使失去的出口短暂可用；必须有落点、身体可通过的路径和协作者维持。不能凭一张门照在墙上开门，不能复原完整城市或死人。
- **代价：** 恢复一个被改写的共同事件时，承载这次恢复的最近一段真实互证关系会先失去细节；高负荷可让对方整段不再认识他。目标不是任意“最重要的人”，也不能选敌人当付款方。训练时先用自己的低价值工作交接承载，仍承担其经济和信任后果。
- **生活：** 工资转账证明他做了活，却不证明同事记得为什么信任他。每次寻求帮助都可能重新成为陌生人；用记事本冒充亲密，会伤害他人。
- **反制与失控：** 源被混剪、跨事件拼接、互斥来源缺标记会使拼接无法闭合，导致短暂定向障碍而非自动给假答案。闻素芬验证来源、普通人核对空间可截停错误。被抓走器材不会令他无能，但会大幅降低可验证性。
- **不可替代选择：** S1E09为救唐姐拼回服务通道，失去她对自己刚形成的信任；S1E12拒绝把一段不完整名单拼成“无人留在里面”的官方证据。

## A02 — Dong Wenhui / 余响

**戏剧职责：** 掌握当下看不见的行动先后，付出越来越难生活在当前声音里的代价。

- **来源：** 2022年地下疏散接线员，身体在安全端，监听线路跨过事故边界，保留未被当下采纳的应答。不是老许的性转或自动亲属；原剧本同事“老许”另有其人。
- **条件与信息：** 需接近实际残留声源、载体或相关接缝；听到的是实际说过的声音，可能是被删除的过去或已形成的候选段。她不能远程监听任何人、读心或向夹页自由拨号。
- **训练：** 先辨方向、重复长度、声场与现时基线；把“我听见”与“属于此刻”分开。与真实敲击、同伴口型及录音作交叉比对。录音机不必收得到她听到的残响。
- **战术：** 识别攻击所用行动段的起步位置与节奏；能报“右侧楼梯还有一组脚步”，不能保证那就是敌人，更不能一句话预知下一刀。
- **代价：** 残响越密，当前听觉越弱；永久损伤先出现在高频和语音分辨，再发展为现实声与残响混叠。静默不是病好了；助听器能辅助现实声，不能筛掉异常。
- **弱点：** 熟悉者声音更容易被赋予错误语境；陆建平可使用真实残声诱导她判断，但不能伪造她从未听过的绝密对话。耳塞不屏蔽已建立的跨侧线路，离开载体可减轻负荷。
- **独立弧线：** 她先以“我最懂危险”控制同行，后来承认自己错过了活人的求救，最终接受由普通人引导当前行动，而不把失聪当圣洁牺牲。

## A03 — Zhou Jing / 守更

**戏剧职责：** 保护一个明确的现时状态，也暴露保护边界之外谁在承担后果。

- **形成：** 事故后首批救援员，为维持一道实际关闭的防水门而停在冲突边界，肉体保住了“这一刻仍撑得住”的联系。
- **条件：** 站在当前相连的有限空间，先确认边界与要保持的人／物／记录状态。初期一段门槛，熟练后一间屋；本季不能覆盖整楼、透过未知房间或随身带全城保护罩。远期P4必须另满足持续多冲突与完整边界条件，不从本季一次保护外推。
- **效果：** 暂缓边界内的现实覆盖；普通人照样移动、流血和受撞击，子弹不会停在空中。固定关门状态可阻止借步借用“门曾开过”的版本，不能防止持锤者真的砸门。
- **持续：** 战术使用按一口气至十余秒的完整行动设计；跨每日窗口的保护须事前固定实体边界和承载物，并由本人守住、同伴维持现实生理状态。不是把战术持续简单乘倍，事后至少失去短期再部署能力。
- **代价：** 冲突延迟不等于删除。默认在施术者身上收束，表现为他维持的一段实际身体经历／身份联系被改写；重复保护可造成旧伤变成新伤、家庭关系缺失。仅当既有承载本就连在同一冲突中、负荷尚未收束且路径可用时可有限分担，完整边界引用W14，不能指派无关路人付款。组织强迫同源活体悬置者承载，在物理条件成立时可能暂缓收束，伦理上仍为暴行；一个行政标签不满足同源条件。
- **反制：** 引导他选错边界、从未锁住的普通出口逼入、持续物理压迫、让他看见边界外正在遇难的人。他主动扩边会放松原边界，形成真实救援抉择。
- **弧线：** 从接受保密的调度结果，到向当事人说清有限保护的代价，拒绝用“上级算过了”免除个人责任。

## A04 — Xie Zhenyu / 借步

**戏剧职责：** 提供追逐、潜入与近身冲突的动作张力；选择越多，连续存在越薄。

- **来源：** 2024年搜寻伴侣时穿过同一疏散通道的两段残留行走，被先后记成已进去与未进去。不是靠速度觉醒。
- **可借内容：** 自己确实执行过、或自己在当前开放冲突里已有源状态的短动作。每次接通一个连续片段，后续可逐段串借相互兼容的动作；上一段落点须支持下一段起势，不能同时占多个位置。不能复制别人的武艺、伤势免疫或任意未来。
- **路径限制：** 开始姿态、落点、支撑与经过空间必须有来源。敌人当前堵住或改变落点，片段就无法成立。可利用既有开门分支越过正在合拢的门，不能穿实体墙、越过从未经过的封闭空间，不能瞬间跨城。
- **危险：** 借到的行动只改变行动连续性，不复位身体。被刀划伤仍会流血，借步途中源状态失效会落在接缝边、跌倒或被卡住。手里忽然多出的武器必须原本就在源片段且可同当下兼容。
- **代价：** 连续两次叠借会出现身体反馈和社交识别断续，旁人可能记住结果却不记得他来过；过度使用可失去返回当下的落点，不是下一次自动满格。照片遗漏是有因果的断联征兆，不能每次都当免费酷炫特效。
- **反制：** 改动路径中的普通障碍、移走落点支撑、让董文慧识别源脚步、用周竞固定门和地面。普通人也可把梯子撤走；不需要另一个更快能力者。
- **弧线：** 早期把“我付自己的命”当作能强迫别人参与的理由，后期承认亲人未必愿意让别人替她死。

## A05 — Wen Sufen / 验契

**戏剧职责：** 找到谁与什么相连，阻止所有谜题都被林序解决。

- **来源：** 修复一批来自事故疏散点的家庭档案时，保存了彼此矛盾的受益人与签收关系；通过一枚真实印章形成跨侧联系。
- **条件：** 物件本身与被删经历有来源关系，接触后只能识别有限的缺失连结：谁曾把它交给谁、某两个角色曾共同在场、哪份文件并非同一来源。不能触摸垃圾就追踪全城人。
- **边界：** 识别关系，不播放完整过去、不判定善恶、不读取未留下的动机。互斥来源要各留一条解释；林序负责恢复动作，她负责确保没把两人的历史接成一个人。
- **代价：** 面孔身份对应逐渐损伤，轮廓仍看得到但不再自动指向熟人；声线、步态、约定与当前相处仍可辅助辨认。不能把脸盲演成失明、失智或对所有人失去感情。
- **反制：** 借用真物件而混淆归属、让中间关系在她介入前已经断掉、以她熟悉的声线冒认身份。她用双重当下验证自保，不拥有绝对识谎仪。
- **弧线：** 放弃把资料独占当作保护人的唯一办法；公开来源边界并容许证人撤回自身隐私，而非最终把全部档案无差别上传。

## A06 — Lin Wan / 留影

**戏剧职责：** 使失踪者有自己的行动与拒绝权；让兄妹之间存在真实的信息和伦理分歧。

- **来源：** 接缝形成时仍在试图把一个人的存在传给另一端，而那段共同经历尚有物质载体。不是因为她是女主妹妹才拥有钥匙。
- **操作：** 在夹页耗散前保留一个已形成影像段，让它沿仍在的关系抵达现实。她能选“保哪一段”，不能指定哪天几点到达、完整带出全部声画或创造尚未发生的胜利。
- **容量：** 一个持续锚只能维持一个核心片段；转存到有来源的载体可以释放注意力，但同一片段不能无限翻拍增强。她同时保护其他人时，必须放弃一部分可给哥哥的证据。
- **未来：** 只有W09限定的候选段能被保留，不是高层全知。看到哥哥在出口后面，不等于知道他最后死没死。她可主动切断某条候选抵达路，代价是自己也失去那条路。
- **代价：** 每次留住片段，会让她当前身体经历与现实日历更难对齐，感到温度／饥饿的时序混乱、错过同伴正在经历的时段；严重时忘记自己刚作的决定，不能靠录像无限规避。
- **合作与反制：** 闻素芬验证关系、董文慧定位片段声音、林序恢复原片可见的动作；源片段先耗散则三人都无法补救。陆建平可迫使她在救一群人和给哥哥发第二条清晰信息间选择。
- **弧线：** 从替哥哥决定“不准来”，到向他提供包括自己责任在内的真实选择；她不把其他悬置者当作自己回家的燃料。

## Worked Confrontation — The Service Corridor

推荐用于S1E06。谢振宇要带走林序去见能辨认旧照片的闻素芬，但瞒着他路线也通望归社交人点；周竞只允许他进官方保护屋。两人都认为自己救他，林序没有同意被任何一方占有。

1. 周竞先确认一间值班室和门槛，守更阻止侧门被换成旧版敞开状态。谢振宇第一次借步抵达原开门落点失败，撞伤肩；不是隔墙瞬移成功。
2. 谢振宇从当下真实楼梯退下，借自己先前走过的外侧检修梯，形成从画面边缘消失、在窗外落脚的动作。观众先看见梯与窗，才看见不连续行动。
3. 董文慧听到外梯脚步，却因残响把落脚先后报错。普通同事老许看见窗台实际滴水和手影，提醒真正进入点。董文慧承认判断有误，调整接应。
4. 陆建平的领路客切断消防通道，迫使周竞在守林序与救边界外一个值班员间选择。周竞撤守更，承受身体旧伤覆盖，转去救人；不是谢振宇“打破领域”。
5. 林序凭门轴新旧漆痕与两段真实监控拼回检修门先前的打开动作，和老许实际推门脱出。门只够这次通过，他失去老许对当天一个工作交接的记忆信任，留下后续关系损伤。
6. 谢振宇取得半张路由图，却没带走林序；周竞救出值班员，却失去林序对官方的信任；董文慧保住出口，却听不清林序之后一句感谢。双方的赢与输都持续影响后续。

动作高潮必须有身体、空间和选择。仅给人物发光、互相对视、闪现残影，无法呈现这里的战术。上述是故事级行动案，尚未形成第二份Director coverage或生成授权。

## Daily Survival And Unsolvable Risk

训练以已知低风险残迹和明确停止条件进行，至少一名不在操作内的观察者记录当前状况；来源不明、症状改变或同伴认不出人时停止。停止不保证恢复已失去的内容。堤务处的强制测试能制造伤害和假阳性，望归社的危险觉醒传说也不能被作者写成可靠捷径。

不存在可解决一切的组合：没来源的失踪救不回；被普通武器致命伤害的人不会被技能复位；完全删除的共同记忆不能循环转账复原；每个人的感知都可能只对应真实的一部分。最熟练的六人聚齐，也可能只知道应当放弃哪条看似有希望的路。
