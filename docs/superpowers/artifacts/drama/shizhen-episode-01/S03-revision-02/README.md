## Coverage And Generation Group

使用Seedance 2.5的一次约18秒生成，包含两个有动机的摄影机位：完整的正常在场、消失与同框受惊，再近景接住受惊之后的反应和求证。时长来自完整过程的容量估计，不是要凑满30秒，也不继续沿用旧10秒短段；不为动作或对白逐秒卡点。

1. **Establish presence and eyeline**：从新首帧的柜台斜向双人中景开始，店员完整头顶到腰部、脸与双手可读；林序侧脸的眼睛、嘴与右手手机同时可见。小程正常准备扫码，林序自然看向近在面前的小程，不低头回避视线，也不预先紧张。此处要让观众来得及认识一个仍在工作的活人。
2. **Absence and immediate reaction in the same frame**：扫码起势后，出现一次短促的画面错帧与轻微明暗抽落，像现实少了一格；紧接的完整画面中，小程与衣服已直接不在。没有身体透明、烟团、粒子或传送门；不能用全屏黑闪、切走或大面积特效藏掉关键比较。枪失去支撑落到原手下方台面，直立咖啡、纸饭团不被带走。林序就在这一瞬眼睛睁大、眉毛抬起、呼吸一滞，肩背本能后缩，右手手机顿住后轻微收回；视线立即锁在刚才店员脸的位置，不能过几秒才抬头发现。
3. **Carry the reaction, then seek an ordinary explanation**：沿同一反应切林序中近景，不能把惊讶重演一次。保留已经停住的呼吸、收紧的手指和同一视线高度；随后才小幅探身看空位，再看柜台下或侧通道，像在验证自己是否看漏。震惊明确可读，但不尖叫，不当场认定灵异，不突然转成面无表情。片尾仍持同一手机、望向空柜台；下一段可以接常识性询问。
