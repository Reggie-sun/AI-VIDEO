## Blender routing

Blender assets/references: load `scenario-blender-expert` first; motion/timing/contact uses `scenario-blender-animation`, rig/IK/FK only `scenario-blender-rigging`, staging/camera/shots only `scenario-blender-previs-storyboard`. Prioritize motion, contact, camera direction and continuity with proxy geometry; deliver editable `.blend` and useful reference video. No new infrastructure unless needed. Blender is not the default final renderer or main pipeline replacement; ordinary video/edit/prompt/reference-image work does not use this route.
