## Story Structure

### Stage One — The Witness Is Not Believed

V01独立测试从普通宿舍切入：小龙、曾亮继续打牌，潘子去阳台旁关窗。潘子看见台风云中的灯笼怪，当前写法还要求在同一主观镜头中看见它原地消失；潘子随后关严窗户、返回报信，两位室友不相信。

这段的矛盾不是“怪物追人”，而是“目击者确认异常、同伴仍留在日常解释中”。观众先拥有怪物信息，再看室友继续打牌，形成信息差。它也提前给后面潘子确认走廊怪物就是窗外怪物建立记忆锚点。当前画布从第13组开始接主线，不能据缺少前12组推断成片没有前情。

### Stage Two — Escape Becomes Impossible

V02–V09的行动依次是发现走廊异化 → 退回606 → 手机失联与时间异常 → 决定下楼找人 → 探门离开 → 发现身后怪物 → 逃回宿舍 → 顶门 → 复盘。每次解释都被新证据推翻：不是只因灯坏，不是只因断网，也不是关门就能理解发生了什么。

其中V07让性格变为可见动作：小龙负责开门和最后关门，潘子摔倒，曾亮与小龙拉他回来。三人的关系由台词打趣转为生存中的互相承担。V08门外撞击停下后仍留在门内，不急着揭示怪物去了哪里，延长“不知道门外状态”的不安。

### Stage Three — A Rule Creates A Concrete Task

V10–V11切到现实地下车库与郭老师，建立“外部有人发现失联，但未必能直接抵达”的救援线。V12–V16回到黑暗宿舍：抱怨、冲动找武器、广播打断、规则怪谈判断、整蛊解释与谨慎意见互相交锋。

V14的第一条规则给出明确行动目标：午夜前，从走廊消防柜附近黑盒取回606滞留牌，挂在门内；否则午夜后门无法挡住外面的东西。这个目标同时包含地点、物件、截止时间、失败后果。恐怖氛围因而转为可执行的任务，不再只有三人讨论。

### Stage Four — Knowledge Is Tested By Action

V17、V18为探门与计时测试，V19归纳怪物在左侧出现三分钟、随后有三十秒空档的规律。V20–V25进入取牌行动：倒数 → 叠手 → 开门 → 小龙留左侧持棍守路 → 曾亮计时/指挥 → 潘子去右侧消防柜取盒 → 潘子摔倒 → 怪物刷新 → 拉人撤回 → 门先关上，怪物扑到门外。

动作戏有左右两条责任线：小龙面对威胁，另两人执行目标；怪物刷新把两条线重新汇合成撤退。潘子不是只在背景害怕，他必须完成取盒任务。V20的英雄式亮相给人物一次“准备勇敢”的短暂姿态，随后V23的摔倒与V24撤退又暴露行动的脆弱。

### Stage Five — Familiar Identity Becomes The Threat

V27开场滞留牌已经挂好，三人坐地听广播。V28–V32用狗哥电话和门外求救制造第二层悬念：熟人的声音促使开门，但潘子的手机又出现“狗哥”来电；门外与电话不能同时被当作可信身份。

V33–V36通过上亮窗反复查看：先看不到人，再出现熟人的惨白脸、微笑和脖颈伸长。V35的忍痛与笑场是短暂泄压，若放在此段，需要用明确前后关系证明笑来自压力和疼痛，不让观众误读为危险解除。

### Stage Six — The Barrier Is Breached

V37–V39让前面一直保护三人的门发生不可逆变化：狗哥头部撞碎上亮窗 → 长颈入室袭击潘子 → 小龙拿键盘反击 → 狗哥缩回并变灯笼怪 → 巨手从同一个破口进入 → 潘子被抓 → 小龙、曾亮合力反打与后撤。

结尾承接对象是“同一扇门、同一个破口、同一组防身道具”，不只是怪物换一种外观。故事从“不要出去”升级到“关门也不安全”。当前库存止于这一类攻击段，不能把它称作完整第一集的正式结尾。

## Visual And Spatial Design

### The Dormitory Is A Repeatable Stage

主要空间不是随意生成的“恐怖房间”，而是床架、牌桌/书桌、阳台窗、绿色宿舍门、门框上方横向上亮窗等反复可识别的区域。前期牌桌支撑日常关系，后期上下铺支撑分散沉默，门内地面把三人挤到同一防线。

“窗”和“门上亮窗”应作为两个不同空间锚点：V01面向台风天空；V36面向门外局部走廊。复用时若只写“窗外有怪物”，模型可能把后段拍成阳台或把玻璃放到门板中央。

### The Corridor Carries Direction And Distance

样本V07、V20、V24可见潮湿长廊、绿色门、黑色藤蔓、顶灯与远处绿色指示灯。透视线把远端威胁和近端人物放进同一空间；V24从空廊到暖灯笼现身，再切回潘子摔倒，使危险距离成为具体信息。

取牌段文本分配“小龙守左侧、消防柜在右侧”。实际剪辑必须有建立位置的镜头，并检查换机位后左右是否仍可追溯，不能把每个构图的画面左都当作同一条走廊的地理左。

### Color Has A Narrative Job

V01约3.97秒样本中，冷灰蓝台风云与暖琥珀灯笼直接对照；约11.92–19.86秒回到室内牌桌，桌边暖灯和人物肤色恢复生活感。后段总体冷青灰/灰绿，暖色怪物光、绿色远端灯、红色滞留牌分别承担威胁、纵深与规则物件的辨识。

值得保留的是局部亮点与冷暗环境的关系。若一律压成青黑，人物表情、玻璃边框和怪物肢体就会失去阅读条件；若灯笼把整条走廊照成橙色，又会削弱远近关系和灯光的来源。

### Damage Must Become Persistent State

门最初关闭、上亮窗完整；V37破玻璃后，V38缩回、V39巨手伸入都必须承接破口。键盘要从书桌取到手中后再成为武器，玻璃不能下一组恢复，潘子的被抓位置与同伴的救援接触要连续。红牌挂好也是阶段状态，后续门内镜头不应随意消失。

## Detailed Shot Cases

### Case A — V01: See It, Lose It, Fail To Convince

文本分配的核心动作是跑到窗边 → 关窗中止 → 看清怪物 → 同一POV内消失 → 关窗扣锁 → 报信 → 室友敷衍 → 急切辩解。不是将怪物画面和人物害怕画面任意拼在一起。

| Observed sample | Picture and staging | What it contributes |
| --- | --- | --- |
| 0.00 s | 黄衣潘子向窗边行动 | 行动从现实事务开始，给看窗外一个理由。 |
| 3.97 s | 窗框内的台风天空；巨大灯笼头部/群簇形成亮点 | 观众实际看到威胁，避免只有台词说“看到了”。 |
| 7.95 s | 潘子窗边侧面，雨幕在外 | 让视线与人物反应回到同一地点。 |
| 11.92 s | 潘子在前景，打牌的室友在后方 | 报信者与不信者的状态同框冲突。 |
| 15.89 s | 黑衣小龙在左、白衣曾亮在右，继续持牌 | 用“继续原来的事”表达不信，比两人同时大喊更具体。 |
| 19.86 s | 潘子又转向窗侧 | 目击后的不安仍存在。 |

可借鉴：先建立日常动作，再让异常打断动作；反应镜头必须接可见刺激；否定/敷衍可由人物持续打牌来演。不能由上述六帧证明3.3–4.3秒原地消失已实现；需要加密该区间并检查云雨/相机连续。

### Case B — V07: Rescue Gives The Chase A Relationship

0秒三人沿湿走廊朝镜头跑，怪物在远后景；约2.97秒有人试门，画面带“打不开”；5.95秒换到怪物在近景/前方、人物在远处的反向覆盖；8.92秒人物转向门；11.90秒潘子倒地，被两人拉起，怪物肢体逼近；14.87秒小龙进入门内，绿色门成为阻隔。

这组有用的结构是“路线受阻 → 同伴掉队 → 回身救援 → 关门成功”。没有潘子摔倒和拉起，追逐只有速度；有了救援，怪物距离同时检验人物关系。反向覆盖要交代摄影机在追逐轴线上的位置，避免把怪物剪到人物前面。

注意样本里的门牌可读为604，当前文本计划是602打不开、最终回606；这是待核对的output/authoring差异，不能凭节点标题称实际606准确。V07烧录了中文字幕，左上还有AI生成标记，即使当前负面文字写了不加字幕/水印。生成负向要求和平台已有标记要分开处置。

### Case C — V13: A Sound Redirects An Action

抽帧顺序可见小龙在上铺 → 从床上下来 → 曾亮反应 → 小龙在地面 → 潘子在上铺转向 → 地面两人听。当前文本把广播设为打断小龙找防身物/出门的触发，曾亮此前试图劝住。

可借鉴：广播不是额外解释背景，而是改变人物正在进行的行为。需要让“动作被打断”可见，例如脚步停止、视线向声源集中、想抓道具的手停住。ASR或旁白存在不能替代这个身体反应。

### Case D — V19–V24: Plan, Commit, Fail, Withdraw

V19约0–8.92秒，三人靠得很近，曾亮的手机照亮脸，他位于主要信息中心；潘子持键盘/物件，边听边反应。11.90秒潘子近景把风险落实到一个人，14.87秒回三人关系。这里手机首先是计时/判断的道具，不需要模型精确画出大量UI。

V20约0–2.97秒延续室内谈话，5.95秒三只手叠在一起，8.92秒切空廊，11.90–14.87秒黑衣小龙持长棍先出门、两位同伴随后。这是决定由语言转为集体行动的可见接点。文本的英雄式升格是导演偏好，单凭静态帧不能确认慢动作倍率。

V24约0秒是远端空廊，2.97秒怪物出现在暖灯笼光中，5.95秒怪物更近；8.92秒黄衣潘子倒在消防柜附近，11.90秒曾亮扶/拉他，14.87秒小龙持棍守在门边、另两人撤退。用三个空间状态连接“风险兑现 → 掉队问题 → 救援撤退”，比同一镜塞完整取盒、摔倒、变形、救人更容易读。

剪辑改进要看V20与V21是否同时选入：两者都有倒数/开门的功能，直接连续可能重复决定和出门。选择一个主版本，另一组只取补充覆盖，避免让三人像走出门两次。

### Case E — V27 And V32: Stillness Can Carry New Information

V27约0秒先给绿色门与红牌，2.97秒三人坐在门内地面，5.95/8.92秒黑衣与黄衣各自抬眼，11.90–14.87秒回到三人一起屏息/听。红牌证明上一行动的结果，听广播建立下一问题。当前文本明确广播内容后配，不能因当前原生视频未听到清楚规则就判定整片规则缺失。

V32约0秒小龙捂住潘子的嘴，随后松手并近距离交流；8.92–14.87秒两人注意潘子的手机、眼睛睁大，曾亮在后方。悬念依赖“门外同一熟人求救，同时手机又来电”，应把门外声源与手机亮起的先后关系保留。只拍手机表情，没有此前门外求救，观众不会理解身份矛盾。

### Case F — V36: The Threat Approaches While The Camera Holds

当前15秒计划：0–4秒从上亮窗内看狗哥站在窗下；4–6秒切小龙疑惑反应；6–9秒回窗内POV，狗哥抬头微笑；9–13秒脖颈向上/向前伸长、脸接近玻璃；13–15秒近距离低声“龙哥”。潘子与曾亮不入镜，门保持关闭，玻璃位于门框上方。

实际样本0/2.97秒可见窗框后的暗处黑衣人；5.95秒小龙脸部近景；8.92秒狗哥微笑进入更亮位置；11.90秒脖颈明显变长；14.87秒惨白脸更靠近镜头。前景横向旧窗框持续提供“仍隔着玻璃”的空间证据。

## Prompt And Reference Method

### References Carry Different Responsibilities

54个图片节点可见角色板、场景/门窗、怪物、异化形态与重复资产。具体例子：`小龙角色开发板(1)`包含同一人物多视图、脸部角度和衣物细节；`图片节点 20 - 副本`是黑衣苍白狗哥正常颈长状态；`图片节点 24`是同身份长颈状态；`666`是从上亮窗看对面门的空间参考。后者实际可见607门牌，不应误把它移到606自身门上。

本次已查看并固定这五项当前served参考，均为720×405 WebP预览；不是4K原图，也没有把文件标题中的4K当作实际像素。角色板的多个视图应解释为一个角色，正常/长颈两图应解释为同一身份的先后状态；场景参考里的红牌、门牌与家具不能不加区分地继承到所有镜头。

可执行的职责写法是：身份图负责脸/发型/体型/服装；状态图只负责本组允许变化后的身体状态；门窗图负责几何位置与材质；上亮窗POV图负责机位与局部空间。每个参考还应注明排除项，特别是sheet排版、文字、额外视图以及不属于当前阶段的伤势/破损。

多个composer显示 `11+-+副本, duration 2s` 的视频参考；库存没有独立audio node，不能据此说没有声音参考，也不能在尚未确认该2秒文件内容时把它称作角色声线。参考节点数和实际进入一次请求的素材数也应分别统计。

### A Group Has A Job And A State Change

常见当前写法依次为基础设定 → 氛围与画质 → 画面内容/分镜 → 负面提示词。基础设定写人、位置、道具与允许出现者；分镜部分写时间、景别、机位、构图、运镜、可见内容与声音。V27直接写“本组只完成一件事”，V36写完整恐怖动作闭环，这比复写大量质量词更能约束内容。

每组可提炼成四个问题：上一组已经发生什么？此刻人物在何处、持何物？本组增加哪一条信息或哪一次行动？最后留下什么可接状态？例如V37必须从完整玻璃开始、以破口结束；V39从破口开始，不能重新演一次撞碎玻璃。

### Negative Text Should Follow A Specific Failure

V36针对性排除了门打开、门中央玻璃/猫眼、完整走廊、潘子曾亮入镜和提前变灯笼怪。这些约束各自保护明确的信息揭示或空间事实，具有复用价值。反复列出所有通用负面词则不保证执行，实际样本已经显示字幕/标记仍存在。

V06曾亮角色段落中出现“小龙角色开发板(1)”chip，与人物名不一致；V34“小龙从潘子支撑处跌下”和V35文本的前置摔落说明也不完全一致。先确认选用版本与实际绑定，再修角色/状态指向，不用增加“保持一致”掩盖具体矛盾。
