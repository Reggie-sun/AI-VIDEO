# EP01 v2 表演修訂：靜幀預覽 prompt 本（v3）

使用者看完成片 c1 的意見：「2s这里没有睁眼的过程是为什么,衔接很弱.后面人物表现一直很弱,唱歌也是」。重做範圍：「S1 睁眼＋副歌＋S5/S7 反應 (Recommended)」。演唱方向：「冷靜但活著 (Recommended)」。

這些靜幀先給使用者看表演力度，認可後才付費生成影片。

**生成方式**

- 用 `motion-kit/tools/codex_plate.py --edit-base <已認可的關鍵幀>` 生成，第一張附件是編輯底圖：保留它的構圖、機位與光線，只改表演或狀態。
- 另附身份錨點 `series/casting/raw/CF-a.png` 與 `series/identity-cf/raw/CF-ID7b-a.png`。
- 畫面中不放文字或介面；資訊圖形與字幕由 motion-kit 後期疊加。
