# Opening Performance Context

## Scene

夜间应急记录台。值班转报员把各处来电交给董文慧记录；转报员不在异常现场。董文慧用桌面扬声器接报，边记录边确认数量与地点。异常事实造成不安，角色仍在完成眼前的值班工作。

逐句潜台词、说话动作和轻重落点为本次导演补充，不新增剧情事实，也不是已确认的心理设定。

## L1 · 值班转报员

> 检修口报，电闸断了，绞盘还在收

- 接到什么：转报员刚接到检修口的来电：来电称“电闸断了”，绞盘仍在收卷。
- 对谁说：夜间记录台的董文慧。
- 要做什么：把报告来源和矛盾现象交代清楚，让她能立即记下并继续处理。
- 潜台词（不朗读）：先把这件解释不通的事实记准，别把来源和现象混在一起。
- 声音行动：先自然带出“检修口报”，把“电闸断了”作为已收到的条件，再接“绞盘还在收”。后半句让矛盾落地，不把每个短语读成一条播报。
- 说完以后：信息交给记录员，等她处理；不自加解释或补一句感叹。
- 知识边界：只知道来电内容，没有亲眼看见绞盘。不得演成在现场喊话的工人。

**可送入当前模型入口的候选：**

```text
[night dispatcher relaying a caller's report, speaking plainly to a record keeper] 检修口报，电闸断了，绞盘还在收
```

## L2 · 值班转报员

> 七号楼报，下了三层，还在原来那层

- 接到什么：上一条报告交出后，转报员接到七号楼的新信息：住户说下了三层，却仍在原来的楼层。
- 对谁说：仍在接报记录的董文慧。
- 要做什么：让听者听懂住户描述的空间矛盾，保留“下了三层”和“原来那层”的区别。
- 潜台词（不朗读）：这话听着不对，但这是来电者说的，我得把意思说清楚。
- 声音行动：“七号楼报”是工作中的来源说明；“下了三层”正常说完，“还在原来那层”略作重新确认式的落点。允许思考感，整体仍是对同事说话。
- 说完以后：报告交出，继续等待下一条信息，不故意拖长句尾制造悬念。
- 知识边界：没有自己走过楼梯，不把住户经历演成转报员的第一人称惊恐。

**可送入当前模型入口的候选：**

```text
[night dispatcher explaining a caller's confusing account to a record keeper] 七号楼报，下了三层，还在原来那层
```

## L3 · 值班转报员

> 急诊说，系统里她已经死了，人还躺着

- 接到什么：刚收到急诊一侧的报告：系统把她登记为死亡，人仍躺在病床上。
- 对谁说：负责把信息记下来的董文慧。
- 要做什么：把“系统记录”和“人在病床上”这两个信息都转述到位，不替急诊下医疗结论。
- 潜台词（不朗读）：我也不能替他们解释，先让你把这个矛盾听明白。
- 声音行动：“急诊说”像刚听完来电后的转述，不用播音开场。“系统里她已经死了”交代记录，“人还躺着”接出矛盾；句末说给对方听，避免恐怖旁白式压低和夸张重音。
- 说完以后：话留给记录员接收，不补充“人还活着”等原台词没有的结论。
- 知识边界：转报员不在病房，也不知道异常机制；护士和病人的可见动作不自动成为转报员目击事实。

**可送入当前模型入口的候选：**

```text
[night dispatcher relaying an ER call, quietly emphasizing the contradiction] 急诊说，系统里她已经死了，人还躺着
```

## L4 · 值班转报员

> 人民路有人喊救命，在七楼，七楼早就封了

- 接到什么：接到人民路的求救信息，报告地点在早已封闭的七楼。
- 对谁说：董文慧。
- 要做什么：先让她定位求救地点，再补充楼层早已封闭的限制。
- 潜台词（不朗读）：先抓住人在哪里；封楼这件事也必须跟着记上。
- 声音行动：“人民路有人喊救命”带着处理来电的目的，“在七楼”收窄位置，“七楼早就封了”是紧跟着补上的关键信息。焦点明确，工作语气里有注意力，不尖叫、不拖成悬疑预告。
- 说完以后：报告说完即交接；木板后的“救命”属于现场声，不能由这个转报员再补念。
- 知识边界：只转述来电，不假装自己正在楼下拿手电照窗。

**可送入当前模型入口的候选：**

```text
[night dispatcher relaying a call about a sealed floor, focused and restrained] 人民路有人喊救命，在七楼，七楼早就封了
```

## L5 · 董文慧

> 记上，第十四起

- 接到什么：董文慧听完这一组转报，在纸本记录上新增一行，确认累计数量。
- 对谁说：主要是她自己；桌面记录动作与这句话在同一处境里。
- 要做什么：把数量落实到记录上，然后继续值班。
- 潜台词（不朗读）：又一条。先把它记清楚。
- 声音行动：声音向内收，但保持完整发声。“记上”像做事时给自己的短提醒，“第十四起”是核对数量后落下的一笔。语气来自记录动作，不把数字当作片名或悬念台词。
- 说完以后：确认落在纸上，收住声音，转入下一次例行询问。
- 知识边界：她知道自己记了多少起；不让她提前知道站台将发生什么。疲惫只能作为导演可选细节，原稿并未规定她已疲惫。

**可送入当前模型入口的候选：**

```text
[record keeper making a quiet note to herself while writing the case count] 记上，第十四起
```

## L6a · 董文慧

> 三号站台

- 接到什么：记完数量，董文慧例行询问三号站台的情况。
- 对谁说：值班转报员。
- 要做什么：得到这个地点的当前报告状态。
- 潜台词（不朗读）：那三号站台呢？
- 声音行动：短句要有明确询问对象。“三号”负责定位，“站台”轻微保留问意，给对方应答空间。保持原文“三号站台”，不新增“呢”或额外说明，不因观众将看到站台就预演担忧。
- 说完以后：停下来听答复；问答间隔交给后续实测与唯一时间线安排。
- 知识边界：她不知道站台接下来发生的异常，这只是例行点名。

**可送入当前模型入口的候选：**

```text
[record keeper asking dispatch for the status of platform three, routine enquiry] 三号站台
```

## L6b · 值班转报员

> 暂无报告

- 接到什么：转报员听见董文慧问“三号站台”。
- 对谁说：董文慧。
- 要做什么：用最简短的工作答复交代当前没有报告。
- 潜台词（不朗读）：目前没有这一处的报告。
- 声音行动：承接对方问句，直接答复，不重新起一个播报段落。正常、利落地落下“暂无报告”；没有故意放空的停顿，也不在“暂无”上做讽刺或阴森暗示。
- 说完以后：答复结束，把声音让给站台雨声与后续原片，不加解释。
- 知识边界：不知道站台即将发生什么；不能把观众的预期演进声音里。

**可送入当前模型入口的候选：**

```text
[dispatcher answering the record keeper's location enquiry, routine and direct] 暂无报告
```
