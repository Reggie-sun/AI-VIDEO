后续用户明确“B的终态你也可以变化，如果你觉得更高级”：B现为方向锚点，不再是必须回到的终态。以下三次图像请求已在此前提交，保留原请求与产出，不篡改为事后方案；返回后按字形、空间厚度和非海报化程度统一筛选，可将更强的中间状态发展为新的终态。

原提交方案以用户选中的 B 终态为参照。用户明确拒绝前一组由左向右推进的擦除，本组不沿用推进边界，也不换成另一方向的擦除。

| State | Visual Responsibility |
| --- | --- |
| 01 | 复用正常彩色入口，空位与幸存者同处一座站台 |
| 02 | 左侧空位深处的城市中间调先失去，近处雨滴、立框与长椅仍有光学厚度；无片名 |

变化依据前后景深与影调，不依据屏幕左右位置。以上是设计目标，实际图片的符合程度见receipt.json。无固定时长，无新剧情事件，无新视频生成。图片只作后期/导演状态参考，不代表已经获得动画连贯性或最终艺术验收。

## Protected Boundaries

不变目标为同站台几何、同机位、同人物与电话手势、同字标最终结构和位置、已有AI来源标识。生成编辑不保证逐像素保护，实际偏差应如实记录。正式时间信息和字形动画仍由后期系统完成，图片不自动提交Seedance。
