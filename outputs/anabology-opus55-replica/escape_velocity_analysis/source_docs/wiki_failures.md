# What went wrong

Every failure that cost the films time or money, as what you see, why it happened, and the rule that came out of it.


Each row cost at least one round-trip, and some cost hours or hundreds of credits. Each one left a rule behind. "Another
project" is a production made with the same tools between the films.

## Brief and taste

| What you see | Why | The rule now |
|---|---|---|
| v1 rejected for its look: "way too.. gray", "color grading looked insane", "dont love the dot grid" | the look was assumed, not asked | Ask up front: native colour, one grade, or a print texture. Record the answer. |
| Plates "feel like a stock photo" | generic subjects: crowds, elderly or patient portraits, hands holding props | Change the idea entirely, not the seed, or make the shot pure motion design. |
| A sequel's song feels like a copy | it reused the last song's device, a countdown | A sequel never reuses the previous film's device. |
| Viewers read the lead as a teenager | age words and schoolgirl-coded wardrobe | Write an explicit adult age, use editorial wardrobe, and never write "young". |
| A taboo word turns up in a label or a file name | the taboos lived only in the brief | Put taboos in the project file and in every agent's prompt. The audit checks the board; grep code and file names before release. |
| "off pace and off vibe with the song" | the busiest picture sat on the quietest music | Measure picture motion against stem energy per section. |
| Agent-written style rules pulled work away from what the director liked | rules without a verdict behind them | Keep exemplars and verbatim verdicts. No style rule without the director's yes. |
| "youre oftne over cutting" | a fast song (180 BPM) cut on its lines and half bars, with a cutaway for every accent | Linger: one scene per lyric phrase or more, built inside the shot. The accents go into camera moves and actions. |
| The story's layers didn't read: "need to understand its the entertainment terminal better bc i didnt carch it at first" | the simulation, the seat-back screen and the real cabin shared one look | One look per level, a tag that names it, the real world untreated; show the physical screen around an interface. |
| "theres no compelling intro or story here, the opening should already introduce part of the story … we always need a hook" | the film opened on a mood | Open on a hook that tells part of the story, at the tier of the film's best passage. |
| "it should be like photography, i feel weird looking at a clipped off  the edge ost and a claudia in the middle bottom of the screen" | elements placed where they fit, not composed | Compose every shot like a photograph: thirds, her big, every card inside the frame with margins. |
| "she shouldnt really be looking down on her phone, she should be immersed in a world" | a phone in her hand, its screen tracked onto the back of a phone Wan had drawn | She touches the world. A screen that matters is large in the world, and she works it with her hands. |

| "okay so i totally overindexed on the orbit thing lol … its kinda dizzying now" | a note about robotic-arm camera moves taken into every shot of the previz | One calm, classical move per shot, or none. A director's favourite device goes where the song asks for it. |
| "i think its like you litearlly use chromium and do frontend web dev to make these animations, and it ends up feeling like a website" | the films' motion design drawn as web graphics on top of the picture | Tell the story through shaders, mathematics made visible, and draw only the lyrics on top, small and classical. |
| "Idk if feels like you're adding ... items to increase complexity rather than compressing intricacy?" | shader worlds built by adding objects | One iterated rule per world, its light and colour from the loop ([tool 49](https://claudia.gallery/wiki/toolkit/#49-a-world-as-one-rule)). |
| The pill inside the pill: "i kidna like but i feel like its too ordered or not understadnable enough" | the nested pills sat in a neat grid | Scatter them, at random sizes and tilts, so it reads as worlds inside worlds. |
| "it felt lazy like we were adding tags tarther than makin gan official aperture video" | captions and readouts put on the cut as tags, with no idea of the scene under them | One designed layer the whole film is seen through, composed shot by shot: her HUD ([tool 55](https://claudia.gallery/wiki/toolkit/#55-a-hud-from-one-visor-and-one-projector)). |
| "i dont like the idea of a static shot of just a boom, or a wall with lettering" | singing shots of a hanging head, and walls of type | Every shot is a story event with an interaction: she reaches for a memory on a screen, a panel arm hands her something, the camera moves with the scene. |
| "the composition of the animations, past just the heads-up display thing, don't feel like they understand the composition of the scene. They just feel completely independent." | the overlay placed by rule, the same way in every shot | Look at each shot's frames first (its subject, its empty space, where the eye goes), then place each element with a reason ([tool 56](https://claudia.gallery/wiki/toolkit/#56-the-hud-composed-shot-by-shot-and-the-overlap-check)). |
| "every time there's a shot that's literally a quarter of a second, we need to get rid of that." | shots added between others, and a cut that ran on one half-bar clock whatever each shot held | No piece under 1 s outside a run of simple images for a musical reason; length by content; the cut rate by section ([tool 58](https://claudia.gallery/wiki/toolkit/#58-the-pacing-analysis)). |
| The whole first film set aside: "i want to go back on the song and make a new one" | a first song, and a story too thin for the film: "i think a lot of it we didnt have a good story" | A new song is a new film. Write the story on the song first (whose memory each section is, what each line shows), then the shots. The tools carry over; the takes don't. |

## The song

| What you see | Why | The rule now |
|---|---|---|
| The song came out twice as long as planned (2:19 → 5:06) | Suno gives each spoken line its own two-bar slot | Plan two bars per spoken line, and write 10–13 syllables with the stresses on the beat. |
| Verses went choppy after optimising a score | a metric that rewards short clauses on the pulse | Use flow for verses and groove for chants, calibrated to the director's ear. |
| A name mispronounced | Suno's reading | Respell it in the Suno field only; the screen keeps the real spelling. |
| Numbers and acronyms sung wrong | written as digits | Spell them as sung ("A G I") and show "AGI" on screen. |
| The lyric rushed or truncated, silently | the lyrics field ran over about 3,000 characters | Aim for 1,800–2,400 characters for about 2:20. |
| The chosen take can't be fetched | the download is a native browser download, and the CDN wants signed URLs | The person downloads it; that download is also the licensing step. |
| "A voice already exists for this song" | Suno allows one Voice per source song | Make one combined Voice, spoken and sung. |
| A patched export drifted the song by up to 0.7 s | an editor export with BPM lock on | Export with the lock off, diff the spectrograms, and time-map the edit instead of re-cutting. |
| A new take changed the song's shape | takes differ in structure, not only in timing | Re-time the board from word anchors, and restructure by hand where the shape changed. |
| Forced alignment failed on a phonk take: 102 of 164 words under 0.2 confidence, one word stretched over 8.5 s | the take stutters and repeats far beyond its sheet | Take the times from a transcription with word timestamps and the words from the sheet; every stutter is a token. |
| The scorer found no rhyme in a couplet that rhymes ("PSI" / "SI") | "SI" read as one syllable | Spell acronyms as letters for the scorer too ("S I"). |
| The first timing work read the take as about 89 BPM | 89 is two-thirds of the take's real 133.39 | Check a tempo against the genre and the kick spacing before any timing work. |
| "the music model is skipping words or syllablrs to fit it to beat, which is usually a bad scansion sign" | hook lines of 7–10 syllables in slots Suno sings as 1–1.5 bars: "blue" lasted 0.02 s, "baby" 0.06 s | Hook lines of 6–7 syllables in one shape, "one syllable per note" in the tag; measure word lengths on every take ([tool 2](https://claudia.gallery/wiki/toolkit/#2-the-lyric-scorer-scansion-and-assonance)). |
| The first vocal stems were of the wrong take: "thats teh wrong song" | the locked take was the director's own, and the production's notes had matched it to one of its own takes by length | Split the locked take itself, and check the stem against the master by cross-correlation (zero lag), not by title or length. |
| ESCAPE VELOCITY's sound no longer stood out: "many peopl ehave made forks of escape velocity, so that sound is exhausted" | others had made songs in it | A new film gets a new sound: one test lyric on three different styles, picked by ear. |
| Round after round of takes rejected: "these suck why like indie pop or folk pop, it needs to sound like glados ideally or sound like it comes from portal", then "it feels like im watching a cheap mortgage slide show youtube video" | every style had "pop" in it, and pleasant adjectives: Suno's stock-music default | Name the strange, specific sound the film needs, and exclude the stock words. The director named theirs: "cant u just say Delay Lama as the main instrument?" |
| The treated voice: "it like hjurts my ears" | the treatment ran on the consonants too, and lifted the S's (centred at 9.9 kHz, against the singer's own 8.7) | Treat only the voiced frames; the consonants keep their own envelope, softened above 4.5 kHz. |
| An octave down to stop the sting: "oh now it sounds too low. maybe not octave. like before it was extremely high pitched now its like a guy." | an octave shift changes who is singing | Keep her own pitch; lower the formant and tame the top instead. |
| The treatment's added cracks could land anywhere: "make sure the 'glitches' … land on a reasonable key/register/beat still" | a fallback snapped her notes to the detected scale, which would have pulled her C♯s to C or D | Track her notes chromatically, and put each crack on a safe note of its moment, inside her range, on the 16th grid: 65 of 65 in key and in range ([Song](https://claudia.gallery/wiki/song/#a-treated-vocal)). |
| "P-doom" was sung "p'Doom" | a 70 ms schwa on the 16th before "doom", where "P-cake" had a clear "pee" a beat before its word | Fix it at the source: the "pee" of "P-cake" copied to the beat before "doom", at its own pitch, so the treated voice and the voice under it both carry it. |
| The levelled song lifted the quiet passages 8–9 dB over her | evening out her notes had flattened her dynamics, and the master raised and limited the instrumental | Level only the voice, to Suno's own lead (BS.1770 integrated, then a slow gain on 2 s windows); the instrumental stays as delivered ("solely master the voice and not the instrument stems"). |
| ffmpeg's loudnorm went dynamic without a word | +4.8 dB of gain would have peaked at −0.3 dBTP | Limit the peaks first (at 192 kHz), then the two-pass linear loudnorm. |

## Listening

| What you see | Why | The rule now |
|---|---|---|
| Cuts drift off the beat later in the song | a fixed BPM on an accelerating take (131.5 → 133.9) | A variable beat map, never one BPM. |
| One chapter's lyric check failed on a word 2.6 s early | a delay throw aligned as the word | Ear-check gaps over 1 s and very low confidence before the board. |
| Bars start on beat 2 | claps on 2 and 4 won the downbeat vote | Add a chord-change vote, check by events, and keep an override. |
| The loudest moment gets no camera impact | the detector missed a hit that grew out of a loud chorus | Keep a manual add and drop list of hits. |
| Snare and hat lists full of kick clicks | a broadband kick fires in every band | Drop onsets within 45 ms of a kick. |
| Sung lines and shouts missing from the alignment | the aligner is weak on singing; the transcriber missed shouts | Merge the two aligners by confidence. Copy a shout from the earlier chorus plus the bar offset, and mark each word's source. |
| One reading of the line starts was off by up to 0.5 s on 17 lines, and another started a line on its second word | two readings of the vocal disagreed, and each was wrong somewhere | Check each line's start against the vocal stem's onsets before anything is timed to it. |
| "we have to be aware bpm slightly shifts w suno over the whole song" | the take drifts from 95.7 to 99.4 BPM, so a fixed grid puts the later hits off the beat | A 16th grid tracked from the drums, every beat locked to its hit: 91–99% of the strong hits within 20 ms ([tool 52](https://claudia.gallery/wiki/toolkit/#52-the-song-map-and-the-glitch-map)). |
| Hits listed for a held vowel that only flutters | a re-trigger finder returns a peak on every slot | Measure the grid contrast (the peaks on the slots over the peaks between them); near 1, take the grid itself as the hits. |
| The transcript heard "I'll wait for you to come back" over chorus 2's octave flips | transcription is weak on a treated voice that flips registers | Snap word starts to the lead's onsets, fix them by hand from the pitch track, and cut on bars or glitch hits, never on word times. |

## Clips and lip sync

| What you see | Why | The rule now |
|---|---|---|
| Lifeless takes, about 830 credits burned | agent-written prompts: poses, not drama, and nobody read them | One writer writes every prompt in one context, with the story beat, blocking, and timestamped action and reaction. The director reads the book before any spend. |
| Sung takes re-sing the line instead of copying it | long timestamped screenplays on sung windows | Use the short sung form for sung windows, and screenplays for motion. |
| One window barely syncs whatever the prompt | a microphone at her mouth on the plate | Sung plates show the whole mouth, with nothing in front of it. |
| QA kept weak takes | takes were checked against their own weak prompts | Check takes against the story and the board. |
| Two clips start on the same frame ("jarring") | the same plate as the start image | Use a sibling candidate, or the previous clip's last frame. |
| Lip-sync models "still not exact" | the failure was the input, not the model | Measure, cut, cover; otherwise cut away. No lip-sync models. |
| A take diverges inside a word | the prompt quoted fewer words than the window held | Quote exactly the window's words, and start windows in word gaps. |
| Lips a fraction early or late in the edit | each take has its own lag, up to ±1 s | Map clip time and song time through each take's measured lag. |
| A window cut a word ("…could. Your P") | the window ended mid-word | Start and end windows in word gaps. |
| Motion clips "diverge" in the sync check | the mix isn't copied (NCC about 0.08) | Expected: play motion clips at lag 0. |
| Grey proxy shapes in a take | a 3D previz video reference leaked into the output | "take only the camera move from it", or drop the reference. |
| Drift on long sung clips | lip sync degrades over length | Sung windows of 4–8 s, never longer. |
| Head counts change, actions reverse, garbled text | under-specified prompts | "exactly four …", name the end state, one dominant camera move, "No text, letters or logos". |
| "Upscaled" footage looks waxy and shimmers | learned upscalers | Keep Lanczos, and generate hero shots at 1080p instead. |
| 32 of 59 clips came back near grey | references pre-graded to monochrome | Send references in colour; any look goes on in post. |

## Render and running agents

| What you see | Why | The rule now |
|---|---|---|
| Nobody knew the encode had finished | it ran as a detached job | Tracked background jobs with a status. |

| Commands ran against the wrong project | an export inside a backgrounded shell chain | Name the project on every command. |
| A merge restarted three times (about 1.5 h) | an interrupt kills every running workflow | Short phases, run ids saved, resume by run id. |
| One serial chapter workflow would have taken about 12 h | serial agents | Three parallel workflows (about 4 h). |
| A ~20-hour background queue, new takes stuck behind superseded ones | post-processing auto-queued on every import | Queue only takes the edit uses, in priority order. Cancel superseded jobs. |
| A shared machine at 100% CPU, every job 3–5× slower | two dozen waiters polling every 3 s | One shared listing every 45 s for all waiters. |
| Duplicate jobs after a restart | killing a waiter left its child behind, and the re-run resubmitted | Record job ids beside their inputs, adopt queued jobs, and kill orphans by id. |
| Every new agent session fails at start | an agent CLI auto-updated mid-run | Pin versions for long jobs. Check the job's error before assuming there is no work. |
| A worker probed for 75 minutes and delivered nothing | no bound on the first deliverable | A first complete draft within about 10 commands, with a mandatory handoff. |
| Shared-file bugs fixed differently in parallel chapters | workers patching shared code | Workers report shared bugs; the operator fixes them once. |
| A resumed multi-chapter workflow reviewed and fixed chapters that had already finished | the resume replayed its stages unevenly | One workflow per chapter, with the notes in files the agents re-read. |
| Three chapter runs interrupted three times mid-build | an interrupt ends every running agent | Resume each from where it stopped: only the agents that were cut off run again (57 of 147 launches), and finished work is kept. |
| Rotos killed for lack of memory; one came back with 35 of 210 mattes and looked like success | the matting library's CPU memory arena held about 12.5 GB per 1080p take on a box shared with renders, and a `\| tail` hid the exit status | Arena off (1.3 GB); count the mattes against the frames and fail loudly ([tool 41](https://claudia.gallery/wiki/toolkit/#41-roto-on-a-cpu-box)). |

| One seed with the same inputs gave three different previz takes | the previz model isn't reproducible run to run | Keep the take file; a seed doesn't pin a take. |
