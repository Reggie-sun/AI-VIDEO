# 闻素芬 Reference Pack

## Story Basis

44岁，存照馆经营者兼旧档案修复师。审慎、有分寸、熟悉工作流程，保管权不等于处置权。视觉状态：暂无既定人像，外观补全候选。原剧情事实与完整关系仍归现有 Character Bible／Season Outline，本页只说明这套参考的取舍。

## Identity Layer

[人物身份底图](identity/identity-v1.png)：正面、四分之三侧面、侧面、全身。使用干燥中性服装与光线，辨认脸部结构、年龄感、发际线和体型。打底衫只为看清比例，不是角色的永久服装。

年龄与发型不是永远冻结；之后换衣、受伤、变老仍要对照这份身份基线，保留同一人的识别特征并另存状态版本。

## Current Scene Layer

[当前场次参考](scene/scene-v1.png)：第五集存照馆候选：接收两组资料 → 核对来源 → 分开归置并收手。

深褐开衫、石白衬衫、规整袖口；两组照片与纸质寄存袋；干燥、无新伤。衣服、雨湿、物件、动作与场地只服务本场，不写回永久身份。动作资料板不自动等于视频首帧，也不证明动态动作连续性。

本场依据尚未拍摄的大纲首出场制作，服装、道具外观和具体站位是视觉候选；未升级为已接受剧情或Production状态。
