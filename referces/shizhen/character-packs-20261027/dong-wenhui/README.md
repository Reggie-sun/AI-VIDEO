# 董文慧 Reference Pack

## Story Basis

28岁，夜间应急文字记录／过去的临时接线员。克制、先听辨再核对，判断快但承认局限。视觉状态：新设计候选。原剧情事实与完整关系仍归现有 Character Bible／Season Outline，本页只说明这套参考的取舍。

## Identity Layer

[人物身份底图](identity/identity-v1.png)：正面、四分之三侧面、侧面、全身。使用干燥中性服装与光线，辨认脸部结构、年龄感、发际线和体型。打底衫只为看清比例，不是角色的永久服装。

年龄与发型不是永远冻结；之后换衣、受伤、变老仍要对照这份身份基线，保留同一人的识别特征并另存状态版本。
