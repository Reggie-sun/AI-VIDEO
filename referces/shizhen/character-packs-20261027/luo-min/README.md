# 罗敏 Reference Pack

## Story Basis

三十多岁，普通夜班工人，主动联系接车的同事。务实、注意当下生活，不预知高峥缺席。视觉状态：既有面孔整理；风格与年龄感待人审。原剧情事实与完整关系仍归现有 Character Bible／Season Outline，本页只说明这套参考的取舍。

## Identity Layer

[人物身份底图](identity/identity-v1.png)：正面、四分之三侧面、侧面、全身。使用干燥中性服装与光线，辨认脸部结构、年龄感、发际线和体型。打底衫只为看清比例，不是角色的永久服装。

年龄与发型不是永远冻结；之后换衣、受伤、变老仍要对照这份身份基线，保留同一人的识别特征并另存状态版本。

## Current Scene Layer

[当前场次参考](scene/scene-v1.png)：第一集冷开场既有素材：联系接车 → 听同事提醒 → 遮挡 → 继续接听。

墨绿雨衣、衣袖与发梢雨湿；黑色斜挎包、左手手机贴左耳。衣服、雨湿、物件、动作与场地只服务本场，不写回永久身份。动作资料板不自动等于视频首帧，也不证明动态动作连续性。

场次资料直接整理现有生成镜头，没有重画或替换其中演员，也没有倒签整段成片验收；原片风格限制保留。
