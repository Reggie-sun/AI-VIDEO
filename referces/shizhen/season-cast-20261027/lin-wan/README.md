# 林晚 Reference Pack

## Story And Design

19岁中国女性，林序的妹妹，失踪时19岁，录像中仍近似19岁。年轻自然的椭圆脸，直眉、清楚的眼鼻关系、略圆的下巴，黑色直发到肩，朴素低马尾，普通偏瘦体型。曾在社区学习和兼职，习惯把坏东西修好再用，能照护同伴，也会坚持自己的选择。自然未化妆皮肤，有独立、认真、警觉的神情，不画儿童、偶像精修或幽灵。外貌是基于文档的新设计，不复制其他女性角色。身份图干净中性；米白卫衣、领口蓝补线、旧黑发夹属于后续录像场次参考。



## Selected Identity

[身份合图](identity/identity-v1.png)包含正面、四分之三侧面、侧面和全身，已实际查看并自主选为后续身份基线。外貌细节属于受托创作补全，剧情事实仍归 Character Bible。中性衣服不是永久服装，后续换装、受伤或变老仍沿用同一人物面部关系，另存状态版本。

## Scene Layer
