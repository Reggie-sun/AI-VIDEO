# 周竞 Reference Pack

## Story And Design

39岁男性，堤务处现场负责人，原城市应急救援指挥员。脸略宽、眉骨平实、短寸发有少量灰丝，颌面结实但不过分健壮，约一米七八。承担现场责任，安静直接，普通现场工作者的疲惫，不是特种兵或秘密警察。



## Selected Identity

[身份合图](identity/identity-v1.png)包含正面、四分之三侧面、侧面和全身，已实际查看并自主选为后续身份基线。外貌细节属于受托创作补全，剧情事实仍归 Character Bible。中性衣服不是永久服装，后续换装、受伤或变老仍沿用同一人物面部关系，另存状态版本。
