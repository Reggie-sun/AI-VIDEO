# 乔立文 Reference Pack

## Story And Design

闻素芬的普通伴侣，文档未指定年龄，视觉补全为四十多岁男性。柔和圆方脸、眼尾浅纹、中等鼻梁、短发略卷和自然鬓角，普通微胖体型。耐心、温和但有生活边界，要求对方承认当下认不出自己，不画神秘组织人员。年龄和外貌是此次创作选择。



## Selected Identity

[身份合图](identity/identity-v1.png)包含正面、四分之三侧面、侧面和全身，已实际查看并自主选为后续身份基线。外貌细节属于受托创作补全，剧情事实仍归 Character Bible。中性衣服不是永久服装，后续换装、受伤或变老仍沿用同一人物面部关系，另存状态版本。

## Scene Layer

次要人物本轮先做身份参考；服装、雨湿、物件和动作按实际场次补，不用中性底图虚构其出场状态。

## Evidence And Use

完整提示词、输出哈希、实际引用和未选历史见上级 batch-manifest.json。后续制图须实际绑定选用身份图；多视角或动作合图不自动当视频首帧。静态看图不证明模型输入效果或动态连续性。用户逐图审看、视频模型效果均 NOT_EVALUATED，未导入或激活 Production。
